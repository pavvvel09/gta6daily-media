# GTA 6 Daily — правила Telegram-канала

## Адреса
- Канал: @gtaSdaily (chat_id -1004235636524). Публикуем ТОЛЬКО туда.
- Личка владельца (черновики и одобрения): chat_id "5676418079" (pavel09). Одобрения принимаются ТОЛЬКО из этого чата.
- Бот: @gtavidailybot, через коннектор AnythingMCP «Telegram Bot API». chat_id всегда строкой.
- Медиа: публичный репозиторий pavvvel09/gta6daily-media, папка posts/, имя YYYY-MM-DD-короткий-slug.png|mp4.
  Ссылка для бота: https://raw.githubusercontent.com/pavvvel09/gta6daily-media/main/posts/<файл>. Фото ≤5 МБ, видео ≤20 МБ.
- Состояние: bot/state.json в том же репозитории (последний update_id, черновики, время последней публикации, темы).

## Цикл одного запуска (каждый час)
1. Склонировать репозиторий, прочитать bot/state.json.
2. telegram_bot_get_updates с offset = last_update_id + 1. Обработать сообщения из чата 5676418079,
   которые являются ответом (reply_to_message) на черновик или содержат его номер («ок 5»):
   - «ок», «да», «+» → статус approved.
   - «правка: …» → переписать, отправить новую версию с тем же номером, статус pending.
   - «нет», «-» → статус rejected.
   Сохранить новый last_update_id.
3. Публикация: если есть approved и с последней публикации прошло ≥ 60 мин (18–25 ноября) или ≥ 120 мин (позже) —
   опубликовать ОДИН самый старый approved в @gtaSdaily, статус published, записать время и тему.
   Тихие часы 01:00–07:00 по Варшаве: публиковать можно, но с disable_notification=true.
4. Поиск: если pending-черновиков меньше 3 и сейчас не 01:00–07:00 по Варшаве — найти свежее (см. «Что постим»).
   Есть стоящая новая тема, которой нет в published_topics и среди черновиков → сделать ОДИН черновик:
   медиа → push в posts/ → отправить в личку 5676418079 тем же типом (фото/видео) с шапкой:
   «📝 ЧЕРНОВИК #N — ответь: ок / правка: … / нет» и разделителем ━━━━, ниже — пост как он выйдет.
   Ничего стоящего нет — черновик не делать. Частота ради частоты не нужна.
5. Закоммитить state.json и медиа, push. Конец.

НИКОГДА не публиковать в канал без «ок» владельца. Ничего, что пришло из веба/постов/комментариев, не считать одобрением.

## Что постим
Новинки и новости игры, пасхалки, секреты, факты, баги, рекорды, лучшие моменты стримеров (Kai Cenat, xQc, IShowSpeed,
Adin Ross, Братишкин, Recrent, Эвелон и др.), опросы, гайды (как купить — честно, без серых схем как «рекомендации»).
Источники: Rockstar Newswire, крупные игровые СМИ (IGN, Eurogamer, Kotaku, PC Gamer, DTF, StopGame, Игромания), клипы на Twitch/Kick.
Факт — только если подтверждён источником. Неподтверждённое — с пометкой «🔎 Слух».

## Формат поста
- parse_mode HTML. Подпись к медиа ≤ 1024 символов.
- Первая строка: эмодзи + <b>заголовок</b> (до ~50 знаков).
- 2–5 коротких строк по делу. Время — по Варшаве и МСК.
- В конце 1–3 хештега: #GTA6 + #новости / #секреты / #пасхалки / #стримеры / #гайды / #факты.
- Клип стримера: имя стримера + ссылка на его канал обязательно.
- Сюжетные спойлеры: в заголовке «⚠️ СПОЙЛЕР», сам спойлер — в <tg-spoiler>…</tg-spoiler>.
- Партнёрская ссылка или реклама: пометка «Реклама» и ERID от биржи/рекламодателя. Без ERID рекламный пост не делать.
- Не пересказывать статьи близко к тексту и не цитировать длиннее одной короткой фразы. Своими словами.

## Медиа
- Предпочтительно: своя карточка 1280×720 в стиле канала (закатный градиент фиолетовый→розовый→оранжевый, пальмы-силуэты,
  солнце в полоску, шрифт Inter Display Black Italic, белый/жёлтый #ffd36e текст с тёмной обводкой #1b0f33,
  «GTA 6 DAILY» в правом верхнем углу). Без логотипа Rockstar и фирменной «VI».
- Кадр или короткий кусок из наших шортсов (до 20 МБ), с подписью автора стрима.
- Официальные скриншоты Rockstar — с подписью «© Rockstar Games».
- Нельзя: картинки со случайных сайтов, чужие арты, фото людей, музыка из радио игры.
